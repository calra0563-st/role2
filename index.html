🔄 구글 스프레드시트(Apps Script) 연동

구글 스프레드시트의 Apps Script 웹 앱 URL을 등록하면 학생 명단을 실시간으로 가져오거나 배정 결과를 스프레드시트에 자동 기록할 수 있습니다.

* 배포 시 '액세스 권한: 모든 사용자'로 설정해야 브라우저에서 안전하게 연동됩니다.
💡 연동 방법 3단계 안내
  1. 구글 스프레드시트 생성 후 상단 메뉴의 [확장 프로그램] → [Apps Script] 클릭
  2. 위 [Apps Script 예시 코드 복사]를 눌러 코드를 붙여넣기 후 저장
  3. 우측 상단 [배포] → [새 배포] → 유형: 웹 앱 선택 후 웹 앱 URL을 복사해 이곳에 입력
